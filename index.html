Property Notes
Existing Equipment
Capture all nameplate data from existing units. Take a photo of each nameplate — don't rely on handwriting alone.
📋 Where to find nameplate data
💡 Photograph every nameplate before recording. If the plate is worn or unreadable, note that — it affects warranty and refrigerant records.
Existing Packaged Unit
A packaged unit contains all components in one cabinet — compressor, coil, and air handler together. One nameplate covers everything.
Existing Outdoor Unit (Condenser / Heat Pump)
MCA and MOCP are on the condenser nameplate. MCA = minimum wire ampacity. MOCP = maximum breaker/fuse size. These determine if the existing electrical can support the new unit.
Existing Indoor Unit (Air Handler / Furnace)
90%+ furnace produces condensate — confirm drain routing before ordering.
⚠️ Replacing an 80% furnace with a 90%+ unit requires new PVC venting, a condensate drain, and a combustion air intake pipe. Add to job scope before pricing.

Space Assessment
Measure the physical space where equipment lives. New equipment must fit — measure twice, order once.
📐 How to measure unit footprint
💡 Measure the existing unit AND the available space. Also measure doorways, hallways, and attic access — the new unit must fit through every opening on the path to the install location.
Condenser / Outdoor Unit Space
Measure the existing pad or space AND all clearances. Manufacturer minimum clearances are typically 12" on sides, 18-24" on service side, and unrestricted overhead for vertical discharge units.

Duct System
Capture plenum and duct dimensions carefully. Plenum mismatch is the most common install day surprise — measure carefully.
📐 Plenum measurement guide
💡 Measure the plenum box itself — Width × Height × Depth. Also count every duct connection (supply runs) coming off the plenum and record each size. Mismatched plenum size = sheet metal fabrication on install day.
Supply Plenum
Count every duct that branches off the supply plenum. Record the diameter of each one.

Electrical
Electrical mismatches cause the most install day delays. Capture everything here so the right disconnect, wire, and breaker are on the truck.
⚡ Electrical terms explained
💡 The breaker for the condenser must be between MCA and MOCP of the new unit. The wire gauge must handle MCA. Wrong disconnect = install day delay. This is the #3 cause of install day problems.
Electrical Panel
⚠️ Federal Pacific and Zinsco panels are known safety concerns. Flag these for the install manager immediately.
Condenser Disconnect
Wire gauge capacity: #14=15A, #12=20A, #10=30A, #8=40A, #6=55A, #4=70A. Wire must handle the new unit's MCA.
